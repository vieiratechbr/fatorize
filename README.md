# Fatorize 📐✨

O **Fatorize** é uma aplicação web interativa e moderna desenvolvida para auxiliar estudantes e entusiastas da matemática a realizarem fatorações de números inteiros e expressões polinomiais de forma rápida, visual e intuitiva.

---

## 🚀 Funcionalidades

* **Fatoração de Números Inteiros:** Decomposição sucessiva em fatores primos, exibindo a forma fatorada em potência (ex: $2^2 \times 3$)[cite: 5].
* **Passo a Passo Visual:** Tabela de decomposição vertical detalhando o processo passo a passo do cálculo[cite: 5].
* **Detecção Automática de Primos:** Identifica automaticamente se o número inserido é primo e exibe um alerta de destaque na interface[cite: 7].
* **Calculadora de Polinômios:** Área dedicada com um teclado matemático virtual de atalhos rápidos (`x`, `^`, `+`, `-`, `(`, `)`) para facilitar a digitação de expressões[cite: 5].
* **Tela de Carregamento (Loader):** Animação interativa de carregamento centralizada com efeito de desfoque (*blur*) em toda a página para uma melhor experiência de usuário[cite: 7].
* **Cópia Rápida:** Botão integrado para copiar o resultado da fatoração diretamente para a área de transferência[cite: 7].

## 🛠️ Tecnologias Utilizadas

Este projeto foi desenvolvido utilizando tecnologias web fundamentais, sem dependências de frameworks complexos:

* **HTML5** (Estruturação semântica)[cite: 3]
* **CSS3** (Estilização avançada, Flexbox e animações customizadas)[cite: 4]
* **JavaScript Moderno (ES6+)** (Lógica de fatoração, manipulação do DOM e assincronicidade)[cite: 5]
* **Google Fonts (Montserrat)**[cite: 3]
